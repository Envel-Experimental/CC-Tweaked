Вы можете отключить эти сообщения, выполнив команду "set motd.enable false".
Используйте программу "edit <имя_файла>", чтобы написать или изменить свой код.
Команда "ls" или "dir" покажет вам список всех файлов и папок в текущей директории.
Используйте "cd <название_папки>" для перехода в другую папку (например, "cd rom").
Команда "clear" полностью очистит экран терминала.
Команда "mkdir <имя>" создает новую папку.
Для удаления файла или папки введите "rm <имя_файла>" или "delete <имя_файла>".
Команды "cp" и "mv" используются для копирования и перемещения/переименования файлов соответственно.
Введите "help", чтобы открыть встроенную справку, или "help <команда>" для конкретной команды.
Введите "lua", чтобы запустить интерактивную консоль для быстрого тестирования кода.
Удержание комбинации Ctrl+T принудительно останавливает любую запущенную или зависшую программу.
Вы можете перетаскивать файлы из вашей системы прямо в окно компьютера в игре, чтобы быстро их скопировать.
Используйте "pastebin get <код> <имя_файла>", чтобы скачать программу по коду с pastebin.
Используйте "wget <ссылка> <имя_файла>" для прямого скачивания любых файлов из интернета.
Команда "id" покажет уникальный номер этого компьютера. Компьютеры с одинаковым ID имеют общие файлы!
Команда "reboot" используется для быстрой перезагрузки операционной системы.
Команда "time" покажет текущее игровое время в мире.
Продвинутый компьютер (advanced computer) поддерживает цветной текст и клики мышкой по экрану.
На продвинутом компьютере можно использовать "fg" или "bg" для одновременного запуска нескольких программ.
С помощью программы "gps" можно узнать текущие координаты компьютера (нужна сеть GPS).
Не забудьте дать имя вашему компьютеру с помощью команды "label set <имя>". Это защитит его данные при поломке блока.
Программы из папки "startup" в корне компьютера автоматически запускаются при каждой загрузке.
Программа "equip" позволяет экипировать инструменты и апгрейды на черепашку без верстака.
Цвет дискеты можно изменить, скрафтив её с красителем, либо нажав по ней красителем (ПКМ).
С помощью динамика (speaker) можно воспроизводить встроенные игровые звуки.
Чувствуете творческий порыв? Постройте принтер (printer), чтобы напечатать книгу! Вы даже можете печатать разными цветами!
Файлы, начинающиеся с ".", по умолчанию скрыты при вызове "list" (как в Linux).
Команда "set" показывает текущие значения всех системных настроек.
Встроенный редактор "edit" автоматически делает бэкапы каждые 2 минуты.

Сообщайте о багах на https://github.com/cc-tweaked/CC-Tweaked. Спасибо!
Читайте документацию на https://tweaked.cc
Делитесь своими программами или просите помощи на нашем форуме: https://forums.computercraft.cc
Вы можете отключить эти сообщения, выполнив команду "set motd.enable false".
Используйте "pastebin put", чтобы загрузить программу на pastebin.
Используйте программу "edit", чтобы создавать и редактировать ваши программы.
Вы можете использовать "wget" для скачивания файлов из интернета.
На продвинутом компьютере можно использовать "fg" или "bg" для одновременного запуска нескольких программ.
Продвинутый компьютер (advanced computer) поддерживает цвета и управление мышкой.
С помощью динамика (speaker) можно воспроизводить звуки.
Программы из папки "startup" в корне компьютера автоматически запускаются при загрузке.
Используйте модем (modem) для связи с другими компьютерами.
С помощью программы "gps" можно узнать текущие координаты компьютера.
Используйте "monitor" для вывода программы на внешний монитор.
Не забудьте дать имя вашему компьютеру с помощью команды "label set".
Чувствуете творческий порыв? Постройте принтер (printer), чтобы напечатать книгу!
Файлы, начинающиеся с ".", по умолчанию скрыты при вызове "list".
Команда "set" показывает текущие значения всех настроек.
Некоторые программы доступны только на продвинутых компьютерах, черепашках (turtles), КПК или командных компьютерах.
Программа "equip" позволяет экипировать инструменты и апгрейды на черепашку без верстака.
Цвет дискеты можно изменить, скрафтив её с красителем, либо нажав по ней красителем (ПКМ).
Вы можете прогонять страницу через принтер несколько раз для печати разными цветами.
Удержание комбинации Ctrl+T принудительно останавливает любую запущенную программу.
Вы можете перетаскивать файлы из вашей ОС в открытый интерфейс компьютера в игре, чтобы их скопировать.
